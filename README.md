# Meu Portfólio

Portfólio de **Alysson Tacito Ferreira**, desenvolvedor front-end.

Site estático feito com HTML, CSS e JavaScript puro, sem etapa de build.

## Rodar localmente

```bash
python -m http.server 8123
```

Depois abra http://localhost:8123.

## Estrutura

- `index.html`: página única
- `css/style.css`: estilos
- `js/main.js`: lista de projetos, pilha de cartões e interações
- `assets/`: favicon e capturas de tela dos projetos

## Publicar

Importe o repositório na Vercel (ou ative o GitHub Pages); não precisa de configuração.
